# Lesson drafts

First-pass versions of the Learn lessons. Ideas, not shipped: each one moves into `app/src/lessons/` only once the one before it is polished.

Backlog, in order: voltage, resistance, Ohm's law, power, series & parallel, capacitor, diode & LED, silicon & doping, PN junction, MOSFET, 3 nm chips.

`fx.ts` and `types.ts` here are the full versions they were written against. They import from `app/src/` paths as they were (`./fx`, `../core/...`), so they need those paths when brought back.
